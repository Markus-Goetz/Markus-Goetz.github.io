HeAT (Helmholtz Analytics Toolkit) is a distributed tensor framework for high-performance AI. It provides a NumPy/PyTorch-like interface for scalable array computation across multi-node, multi-GPU high-performance computing systems, enabling data analytics and machine learning workflows to scale from a laptop to a supercomputer without changing code. HeAT is developed and maintained with contributions from over 30 people.

[View the repository on GitHub](https://github.com/helmholtz-analytics/heat)
